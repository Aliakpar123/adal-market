# Bereke store

Интернет-магазин продуктов и товаров для дома по оптовым ценам с доставкой до двери (статический сайт: `index.html` — витрина, `admin.html` — админка).

Модель «лидеров ЖК» временно отключена: заказы оформляются через `rpc/adal_place_delivery` (имя, телефон, адрес, квартира, подъезд, комментарий). Таблицы и функции лидеров остались в базе, но закрыты для публичного доступа.

Деплой: Render Static Site, publish path `./`, без сборки.

## База данных

Supabase (проект reels-sabak, таблицы с префиксом `adal_`). Сайт ходит в REST API с публичным ключом:
- читает `adal_products` и `adal_zk` (код лидера скрыт);
- создаёт заказы через `rpc/adal_place_order` (цены считаются на сервере);
- заявки лидеров — `rpc/adal_submit_application`;
- кабинет лидера — `rpc/adal_leader_data` и `rpc/adal_leader_action` по коду доступа (10 ошибок за 15 минут блокируют вход).

Демо-доступ лидера: ЖК Северный парк, код `123456`.

## Админка

`/admin.html` — вкладки «Товары», «Заказы» (все ЖК, смена статуса, сводка «Что закупить»), «Лидеры» (заявки: одобрить с выдачей кода / отклонить; ЖК: коды доступа, скрытие, смена кода). Товары и цены: правка цены прямо в списке, редактирование карточки, скрытие с витрины, порядок в каталоге, новые товары, загрузка фото.
- Вход по паролю администратора (хранится в `adal_admin` как bcrypt-хеш, 10 ошибок за 15 минут блокируют вход). Пароль меняется в самой админке.
- Фото загружаются через Edge Function `adal-admin-upload` в публичный бакет `adal-products`; ссылка пишется в `adal_products.image_url`. Если её нет, витрина берёт `img/<id>.jpg`.
- Математика товара: себестоимость (таблица `adal_product_costs`, только для админа) → прибыль с 1 шт. после комиссии лидера, эквайринга, налога и доставки, маржа, наценка и рекомендуемая цена под целевую маржу. Параметры — `adal_settings`, меняются кнопкой «Параметры расчёта».
- Вкладка «План»: «хочу заработать за месяц» (+ необязательные расходы: сотрудники, аренда) → на какую сумму и сколько заказов нужно продать, сколько штук каждого товара, факт за 30 дней. Прибыль = цена − себестоимость − налог − эквайринг (− комиссия лидера, сейчас 0%).
- Вкладка «Финансы»: отчёт о прибыли за месяц (выручка выданных заказов − себестоимость на момент заказа − расходы) со сравнением с прошлым месяцем, касса (оплаты Kaspi/наличные − закупка − расходы), расходы по категориям, заказы «ждут оплаты», журнал записей. Таблица `adal_finance`; у заказов `paid`, `pay_method`, `paid_at`, `done_at` (ставится триггером).
- Доставка: в админке «Товары → Доставка» — рейс машины, заказов в рейсе, платная доставка, порог «бесплатно от» с рекомендацией (порог, при котором доставка съедает ≤ половины прибыли). На сайте корзина показывает плату и «добавьте ещё N ₸ до бесплатной доставки»; плата считается сервером в `adal_place_order` и пишется в `adal_orders.delivery_fee`.

## Модель с лидерами ЖК

Покупатель выбирает свой ЖК и оформляет заказ (`adal_place_order`) — получает 4-значный код выдачи. Заказы дома копятся в «сборе»; когда сумма достигает порога (по умолчанию 20 000 ₸), админ отправляет сбор в закупку (`adal_admin_ship`). Лидер принимает машину, выдаёт заказы по коду и отмечает оплату Kaspi-переводом на счёт Bereke store (наличные не принимаются). Лидеру начисляется 5% с выданных заказов, выплата раз в неделю из админки (`adal_admin_payout`, попадает в расходы «Финансов»). Порог, комиссия и реквизиты Kaspi — вкладка «Лидеры» в админке.

## Telegram Mini App

Сайт работает как Mini App: подключается `telegram-web-app.js`, внутри Telegram показывается кнопка «Назад», имя берётся из профиля, `start_param` выбирает ЖК. Ссылка Mini App задаётся в админке (вкладка «Лидеры» → «Сбор и оплата» → «Telegram Mini App»), ссылки лидеров тогда имеют вид `https://t.me/<бот>/<app>?startapp=<id ЖК>`. Вне Telegram сайт работает как обычно.

## Режим «Скоро запуск»

Пока включён (админка → «Лидеры» → «Сбор и оплата» → переключатель), вместо магазина показывается баннер, список ожидания (`adal_waitlist_join`) и призыв стать лидером; корзина и заказы скрыты. Записи видны во вкладке «Ожидающие» (CSV, источник — лидер по ссылке `?zk=`/`start_param`), лидер видит число записавшихся по его ссылке. Выключение переключателя открывает магазин.
